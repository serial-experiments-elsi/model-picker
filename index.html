Token-cost tips

  • Output costs 3–5× input. Ask for concise answers, set max_tokens, and request structured output (JSON) instead of prose.
  • Cache the prefix. Put stable instructions and documents first; prompt caching typically discounts repeated input by 50–90%.
  • Route by difficulty. Use a fast-cheap model for classification and extraction; escalate to a flagship only when needed.
  • Trim context. Send only relevant chunks (retrieval) rather than whole documents. Long prompts cost money and can reduce accuracy.
  • Mind reasoning models. They bill hidden thinking tokens as output; budget 2–10× more output than the visible answer.
  • Batch where latency allows. Batch APIs are commonly ~50% cheaper.
  • Keep conversations short. Each turn resends history; summarize or truncate old turns.
  • Measure. Log tokens per request and watch % of context used; above ~70% quality and cost both suffer.
  • Even if cost isn't your concern, fewer tokens means lower latency and rate-limit headroom.
